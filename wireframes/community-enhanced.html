Data Sources

  • GitHub API:
    • GET /orgs/openwaterhealth (org info)
    • GET /orgs/openwaterhealth/repos (repo list)
    • GET /repos/{owner}/{repo}/commits (recent commits)
    • GET /repos/{owner}/{repo}/pulls (PRs)
    • GET /repos/{owner}/{repo}/issues (issues)
    • GET /repos/{owner}/{repo}/contributors (contributors)
  • Discord API:
    • GET https://discord.com/api/guilds/{GUILD_ID}/widget.json
  • Fallback Data:
    • data/github-stats.json (updated by GitHub Actions)
    • data/recent-activity.json (updated by GitHub Actions)
    • data/contributors.json (updated by GitHub Actions)

Caching Strategy

  • LocalStorage: 30-minute TTL for all API responses
  • GitHub Actions: Updates static JSON files every 6 hours
  • Rate Limit Handling: Check X-RateLimit-Remaining, fall back to static when low
  • Last Updated Timestamps: Display to users for transparency
